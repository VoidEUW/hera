# Changelog

There is no hand-written changelog any more. Every tag is published as a
[GitHub release](https://github.com/VoidEUW/hera/releases) whose notes are written from the
Conventional Commit titles since the previous tag — grouped into features, fixes and so on, with
a link to the pull request behind each line. A release candidate (`v0.2.1-rc4`) lists what changed
since the last tag and is marked as a pre-release; a release (`v0.2.1`) lists everything since the
previous release, so it covers all of its candidates.

How that works is in [CONTRIBUTING.md](CONTRIBUTING.md#commit-titles-and-release-notes). The
changelog this replaced, up to v0.2.0, is kept in [docs/changelog-history.md](docs/changelog-history.md).
