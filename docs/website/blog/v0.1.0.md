# Hera v0.1.0

**2026-08-27**

The first release. A message typed into the browser reaches a model and comes back as an
answer, with tools, permissions and skills along the way. Nothing before this version worked
end to end; everything after it builds on this.

## What's in it

- **A uv workspace monorepo.** Ten small libraries under `packages/`, one application
  (`hera-core`) serving a SvelteKit interface built into the same directory the API serves.
- **One model event union.** `hera_providers` defines everything a model can emit; nothing
  above it parses text. A malformed tool call arrives as an event, not an exception.
- **Tools as MCP servers.** External tools come from `~/.hera/mcp.json`, in the same shape as
  Claude Desktop's configuration. Hera's own capabilities — `hera__emotion`, `hera__remember`,
  `hera__note`, `hera__skill`, `hera__search` — are mounted the same way, through the same
  client.
- **Web search**, over DuckDuckGo, no API key required.
- **Skills as `SKILL.md` packages**, selected by code — pinned, then `/slash`, then keyword
  retrieval — never left to the model to notice on its own.
- **A git-backed mind.** Twelve regions, one file each, in a real git repository at
  `~/.hera/mind/`.
- **Permissions.** Allow, deny or ask, resolved by pattern and profile. A confirmation card
  suspends the turn and waits for a person; "always allow" writes a rule.
- **Chats and projects**, with the full event stream persisted so a reload always shows what
  actually happened.
- **Attachments, including pictures.** Read in the browser and sent as a field, never pasted
  into the message text.
- **Configurable model endpoints.** Several can be registered in `~/.hera/config.toml`, one
  active at a time; switching takes effect on the next turn, no restart.

## What's not in it yet

- No memory — `hera__remember` and `hera__note` are wired to nothing and say so.
- No `hera__fetch` — she can find a page, not read it.
- No PDFs.
- No command palette; `⌘K` opens Settings.
- No mobile layout.
- Single user, behind a seam meant for more.
