# Hera v0.2.0

**2026-08-31**

v0.1.0 proved a message could reach a model and come back. It forgot everything the moment the
tab closed. v0.2.0 is the version where that stops being true: projects to file work under, a
scratchpad she thinks on between turns, artifacts she publishes as real files, and memory that
survives a conversation.

## What's in it

- **Projects.** Chats can be filed under a project with its own instructions, pinned skills and
  default profile. A **+** on the rail creates one; a project screen at `/project/<id>` holds
  the instructions, the skills, the default profile and its chats.
- **She can ask you something and wait.** `hera__ask(question, kind)` stops the turn, draws a
  card with a reply field where she asked, and resumes the same assistant message with what you
  typed as the result of her own call.
- **A scratchpad, per conversation.** `hera__scratch_write`, `hera__scratch_read` and
  `hera__scratch_list` over `~/.hera/chats/<id>/scratch/` — hers, unread, and gone when the
  chat is.
- **Artifacts.** `hera__artifact_create`, `hera__artifact_edit` and `hera__artifact_read` over
  `~/.hera/chats/<id>/artifacts/` — a page, a document, a chart, a small program, published as
  a file instead of left in a code fence. `.html` renders in a sandboxed frame, `.svg` draws,
  `.md` is typeset, anything else is a download. Editing one is a find-and-replace against the
  existing file, not a full rewrite.
- **Memory.** `hera__remember` writes one markdown file per memory to `~/.hera/memories/`.
  Every memory that's switched on is in her prompt, in full — no retrieval step that can
  silently fail to bring one back. Settings → Memory shows all of them with a space-left bar;
  switching one off keeps the file and gives the space back. `hera__forget` doesn't delete —
  the only thing that removes a memory is a person on that screen. Export `MEMORY.md` to take
  everything with you.
- **She knows what day it is.** UTC always, plus your local time if a zone is set on the
  profile menu.
- **Fixes worth knowing about:** a long answer no longer times out after three minutes of
  silence (raised to ten, and now editable from Settings → Models rather than only by hand); a
  turn that failed before saying anything can be retried; a tool call now knows which
  conversation it's in; a tool call's arguments stop being resent into every later prompt once
  they're long; and several ordering bugs in how a turn's reasoning and tool calls render.

## What moved to later versions

- **Dreaming and experience training** → v0.3.0. Hera re-reading her own conversations and
  proposing changes to her mind and memory.
- **The redesign pass** — the `⌘K` command palette, hotkeys, a mobile layout, and reading a
  skill's bundled files → v0.2.1.
