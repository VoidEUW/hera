# Documentation

How to install, configure and run Hera.

- **Quick Start** — install Hera with Docker in a few minutes.
- **Local Installation** — every way to run Hera on your own machine: Docker, from source, or as
  a desktop app.
- **Configuration** — the model endpoint, environment variables, and the files under `~/.hera`.

Hera is self-hosted. There is no cloud account and no hosted version — every install runs on a
machine you control, and talks to a model endpoint you run yourself.
